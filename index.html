📘 Learn

  • 3/20, 7/22 = number of strands / SWG size of each strand.
  • 70/76, 40/76 = strands / strand size in 0.0001 inch (76 = 0.0076 in = SWG 36). Used for flexible wire.
  • RM = round stranded conductor. The number before it (like 2.0 RM) is the copper area in mm². For example 3/20 is sold as 2.0 RM.
  • Load depends on the copper area (mm²), not the thickness in mm.
